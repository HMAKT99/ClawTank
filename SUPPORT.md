# Getting help

1. **Check the docs.** The [README](README.md) has an FAQ and a [Troubleshooting](README.md#troubleshooting) table covering connection, permission, sound and performance problems. More guides are in the [docs index](docs/README.md).
2. **Search the [issues](https://github.com/HMAKT99/ClawTank/issues).** Someone may have hit the same problem.
3. **Open a [bug report](https://github.com/HMAKT99/ClawTank/issues/new?template=bug_report.yml).** Attach the zip from **ClawTank menu → Export Diagnostics…**. It contains settings and logs, but no passwords or keys.

Security vulnerabilities: please follow [SECURITY.md](SECURITY.md) instead.

ClawTank is a volunteer-maintained open-source project. There's no paid support, but we read every report.
